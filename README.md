# Prince Earl Gabatino — Personal CV

A responsive personal CV and portfolio website for Prince Earl Gabatino, a fourth-year Bachelor of Science in Information Technology student at Davao del Norte State College. It highlights education, skills, academic and creative projects, certificates, and contact links.

## Technologies

- Next.js 16 (App Router)
- React 19
- TypeScript
- Tailwind CSS 4

## Run locally

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in a browser.

To create a production build, run:

```bash
npm run build
```
